# Data

Derived from IMD radiosonde (RS/RW) soundings, July 2001, Trivandrum and Mangalore.

| File | Contents |
|---|---|
| `cbl_heights.csv` | Daily Convective Boundary Layer height (m) per station and phase, estimated by Conserved Variable Analysis (θe vs q). Empty = no clean θe–q reversal that day, excluded from averages. |
| `low_level_jet.csv` | Low-Level Jet core speed (knots) and approximate core height per station and phase. |

CBL heights are derived estimates from θe–q reversal points, not direct instrument readings.
